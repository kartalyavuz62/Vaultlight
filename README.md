# Vaultlight (Pixel Forge)

Top-down stealth game for Game Studio: AI in Game Development.

- Unity 6.4 (6000.4.1f1), URP 3D
- Open the project, then open Assets/Scenes/SampleScene.unity and press Play.
- Folder structure, naming rules and branching rule: see Part III of PixelForge_Midterm_GDD.
- Every AI-assisted script starts with: // AI-assisted: <tool>, <date>; reviewed by <member>
- No API keys in this repository.
